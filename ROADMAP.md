# Roadmap

- Validate and maintain each project using its own documented setup and tests.
- Compare similar features and capture regression tests before sharing code or
  changing existing interfaces.
- Add repository-level automation that exercises projects independently.
- Develop project ideas here rather than creating new scaffold repositories.
